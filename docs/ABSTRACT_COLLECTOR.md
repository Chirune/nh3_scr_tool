# NH₃-SCR 摘要采集 EXE 0.2

用途：第一步收集摘要并初筛可用论文。此版整理题录和摘要，不进行正文性能提取或机器学习训练。

Windows 电脑双击 `NH3SCR_AbstractCollector.exe`。无需安装 Python，无需 Elsevier API key。

## 方式一：从当前浏览器页面采集

1. 将交付文件夹保存在电脑上；其中 `browser_extension` 是采集按钮。
2. 在 Chrome 扩展程序管理页开启开发者模式，选择“加载已解压的扩展程序”，选择 `browser_extension` 文件夹。Edge 可在自己的扩展管理页按同样方式加载。第一次需要用户自行安装。
3. 打开学校能访问的论文页面，确认能看到 Abstract。
4. 点击“NH3-SCR 摘要采集按钮”，再点“读取本页摘要”；核对标题、DOI、摘要，点击“保存采集文件”，得到 JSON。
5. 打开 EXE，点击“添加文件”选中 JSON，再点击“整理摘要并初筛”。可一次添加多篇文件。

按钮由用户点击后读取当前页面，保存题录、摘要、来源网址、定位和采集时间。不会自动翻页、登录、获取 Cookie 或后台扫描其他页面。这是本地扩展原型，尚未上架扩展商店。

## 方式二：Zotero 收集后导出

1. 使用 Zotero 和 Zotero Connector，在论文页点击 Zotero 保存按钮。
2. 在 Zotero 中检查记录是否有“摘要”字段。网页未提供的摘要，导出不会凭空补出。
3. 选中论文或集合，右键“导出条目/导出分类”，优先选 **CSL JSON**，也支持 **RIS**。如 RIS 导出有“导出摘要”选项，请勾选。
4. 在 EXE 中添加导出文件，整理摘要并初筛。

本版以导出文件对接 Zotero，没有把 Zotero 本体嵌入 EXE，不修改 Zotero 数据库。只导入题录和摘要；PDF 附件将在下一阶段接入正文提取。

## 方式三：用户保存 HTML

1. 打开论文页，确认摘要已加载、展开。
2. 按 Ctrl+S，保存“网页，仅 HTML”或完整网页。HTML 必须实际含有摘要文字；只包含脚本或跳转页时无法离线取得摘要。
3. 在 EXE 中添加 `.html` / `.htm`；也可添加文件夹批量读取。

也支持现有工具的 `records.json` / `records.csv`，便于与检索清单合并。

## 结果与审核

每次建立独立结果文件夹：

- `records.csv`：DOI、题目、年份、摘要、来源、初筛判断和原因，Excel 可打开。
- `records.json`：完整题录，后续可载入原下载工具。
- `manual_review_template.csv`：人工核对表。
- `import_errors.csv`：无法读取的文件与原因。
- `summary.json`：处理计数和范围。

“相关”只是规则初筛，不代表全文一定有足够数据。缺摘要、截断、缺 DOI 和冲突均保留待核对。相同 DOI 去重；不同摘要保留替代文本和冲突标记，不静默覆盖。

打开 `manual_review_template.csv`，重点核对：论文是否实际研究 NH₃-SCR、催化剂是否为研究对象、是否为原始实验研究。`manual_decision` 填 `target`（确认相关）、`non_target`（确认不相关）或 `review`（仍不确定）；`reviewer` 填核对人，`reviewer_notes` 写理由。本版输出核对表，人工决定的回读衔接使用原文献下载工具；再次导入 EXE 会重新进行规则初筛。

下一步核对材料与反应是否为实际研究对象，再获取正文和补充材料，提取样品—条件—性能数据并审核。摘要清单不能直接当作催化剂性能训练集。

## 验证范围

2026-09-29：76 项回归检查通过。EXE 已通过界面启动、真实题录批处理、与 Python 结果一致性及 CSV 回读验证；界面处理和摘要预览也已验证。真实 ScienceDirect 摘要 HTML 与浏览器读取文字一致。

本次浏览器补齐 32 篇原先缺失的摘要，测试清单由 48/80 篇有摘要提升为 80/80。采集时保留摘要内链接的文字，逐篇匹配 DOI。这个结果证明本次页面的采集路径可用，不代表所有出版社、所有页面均可自动读取。

浏览器按钮的安装及“保存采集文件”操作尚未完成用户浏览器端验收，需要安装后进行首次保存测试。当前可直接采用已经验收的 HTML / Zotero 导出文件导入路径。此版使用规则初筛，没有调用 DeepSeek 或 Ollama；文章类型、实际材料和反应仍须人工确认。

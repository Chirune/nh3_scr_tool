# 浏览器采集插件与完整工作台

此插件随工作台 0.8 提供，可采集当前论文页的题录、摘要、可见正文、表格及材料链接，并调用 Chrome 下载 PDF、补充材料和论文图片。

## 安装或更新

1. 解压完整 Windows 交付包，保留 `browser_extension` 文件夹。
2. Chrome 地址栏输入 `chrome://extensions`，打开右上角“开发者模式”。
3. 点“加载已解压的扩展程序”，选择交付包中的 `browser_extension` 文件夹。不要直接双击其中的 HTML 文件。
4. 如果以前装过旧版，移除旧版后加载这次的目录；若你替换了原目录中的文件，则点击扩展的刷新按钮。
5. 在浏览器右上角扩展菜单中固定“NH3-SCR 论文采集按钮”。

## 采集并进入数据提取

1. 打开你能访问的论文页面，展开 Abstract 和正文。
2. 点击插件图标，再点“读取本页”。核对题目、DOI、摘要以及“可见正文”状态。
3. 点“下载文件并保存采集包”，保持插件窗口打开，等待文件下载和 JSON 保存完成。只需要网页文字时可点“仅保存采集包”。
4. 打开 `NH3SCR_Workbench.exe`，在第 1 页添加刚保存的 JSON。
5. 在第 2 页核对摘要和阅读评分，确认相关后保留论文。
6. 在第 3 页选中论文。点“自动获取所选论文正文”优先使用采集包记录的已下载 PDF；点“使用浏览器采集全文”绑定网页正文和材料。文件下载失败时，可从浏览器手动保存后添加本地文件。
7. 核对绑定材料的标题、DOI 和实际内容，再提取；第 4 页对照原文审核，最后导出。

JSON 会记录下载文件的本机路径。导入工作台前不要移动或删除这些文件；如需迁移电脑，应先导入工作台归档，再复制整个项目文件夹。

## 读取范围

插件只能采集当前页面实际加载且可访问的内容。仅有摘要的页面不会生成完整正文，图片中的曲线也不会自动变成准确数值；曲线需在工作台标定取点。网站拒绝下载或要求额外操作时，检查 Chrome 下载列表并手动完成。不要把“已保存 JSON”当成“已成功下载全文”。

每次点击处理当前论文页。工作台支持批量获取清单中的论文；插件当前不自动遍历所有标签页。

# NH₃-SCR 文献数据项目进度

更新：2026-10-01。**阶段 1.2：用不同论文检验数据提取与分类。**工作台的操作链路已跑通，跨论文抽取覆盖率尚未达到批量建立训练集的要求；机器学习、SISSO、实验和 DFT 尚未开始。

## 研究目标与路线

从原始研究中把**催化剂样品、活性中心及结构、反应温度/压力/进料等条件、转化率与选择性**连接到同一实验和原文证据。先获得可核对的数据，再分析影响性能的关键变量，最后由研究团队通过实验或 DFT 验证候选催化剂与条件。

会议记录提出的五项任务，落实情况如下：

| 任务 | 当前结果 | 下一步 |
| --- | --- | --- |
| 摘要筛选、权重打分、DOI | 80 篇题录的摘要已在本地取得；0.5 版按六类可调整权重排序，显示命中原句；论文仍需人工决定 | 以人工判断评估排序，不把分数当作论文质量 |
| 全文和数据获取、来源与权限、统一单位 | 工作台可对已保留论文逐篇按 DOI 尝试开放 PDF 并自动归档；仍可手动绑定 PDF、HTML、补充材料和表格，保留出处并规范常见单位 | 测试更多出版商及权限情形；补充材料获取和出版社 XML 解析尚需打通 |
| 自然语言信息收集 | 规则收集比较、倍数、抑制和机理等原句，独立输出候选 | 将样品、基准、指标和条件准确关联；“提高十倍”不直接作为绝对性能 |
| 精确编码 | 已有文献—样品—条件—观测—证据结构，以及人工审核状态 | 完善跨页、跨图表的关系及样品特征，冻结训练字段定义 |
| 比较机器学习模型 | 尚未启动 | 数据质量达标后，再比较随机森林等模型并评估泛化能力 |

“先收集出来”用于保留原始候选及出处；是否进入训练集，由后续审核和字段完整性决定。

## 本轮可以展示的成果

- **工作台 0.5**：摘要导入、评分排序、论文人工确认、逐篇按 DOI 获取开放 PDF、材料绑定、规则提取、PDF 原始页核对、图中取点、补录、审核与导出形成闭环。自动保存审核历史；未确认论文和未审核记录不会作为合格数据直接使用。
- **软件测试**：本地 108 项自动测试通过；0.5 EXE 的摘要导入、自动归档、证据显示、保存恢复、导出门槛、评分、语义候选和图中读数接口完成验收。自动获取还用一篇真实 Cu-CHA 论文 DOI 验证取得了开放 PDF。软件验收中的合成数据与科研观测分开。
- **真实论文小样**：对 Cu-CHA 论文，通用全文规则在 17 个正文内容块中取得 **3 条数值候选**，另收集 **102 条语义候选**。两类都是待审核候选，不能据此称全文性能数据已提取完整。
- **图中读数衔接**：既有 Fig.1a 的 **46 个**矢量点经过新图片接口往返检验，保留 **3 组**曲线及近似读数标记。这验证坐标转换接口，**不构成独立的科研精度验证**。
- **已有单篇深入整理案例**：历史材料中有 2020 和 2026 两篇较深入的核对成果，包含人工标注及程序检查；单篇规则适配与补全不能代表跨论文自动提取效果。公开进度只保留汇总，不上传论文全文、图像快照或逐条原文。

## 距离可建模数据集还差什么

1. 在 3–5 篇新的原始研究中，逐篇建立人工对照记录，涵盖不同催化剂体系、出版社格式及补充材料。
2. 对每篇核查样品、温度、空速、进料、性能、结构表征及证据定位，统计漏提、错样品、错单位与错条件。
3. 针对高频错误改进抽取和图中取点；重新运行盲测论文。只有经专家核对且字段足够完整的记录才进入建模表。
4. 再确定预测目标、样品与反应条件特征、按论文分组的评估方案，开始比较模型或寻找可解释公式。

目前最紧要的是第 1–3 项。下载或测试记录数不是机器学习样本量；本轮未声称已形成可用于泛化预测的数据集。

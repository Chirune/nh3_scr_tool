# NH3-SCR 文献数据工作台 0.8

双击 NH3SCR_Workbench.exe，无需安装 Python。五个页签按顺序操作。

公开交付包只带两条合成演示摘要；“现有 80 篇摘要”只适用于本机内部版本。浏览器插件安装和采集步骤见[浏览器采集说明](BROWSER_CAPTURE.md)（Windows 包内对应“浏览器插件说明.md”）。

1. **统一检索与摘要**：在第 1 页输入检索词，点“在线检索并加入清单”；默认搜索 OpenAlex 和 Crossref。上方“接口设置”可输入 Elsevier、Springer Nature、OpenAlex key、Elsevier InstToken 和 Unpaywall 邮箱；有对应 key 时还会加入相应出版商检索。也可使用本地 80 篇摘要，或添加浏览器 JSON、HTML、Zotero CSL JSON / RIS。从 GitHub 克隆的源码只有两条合成演示摘要，不得用于科研。
2. **预取与核对论文**：想像旧下载器那样先抓十几篇，可在第 2 步点“预取下一批”，默认按阅读评分从规则初筛相关、尚未人工决定的论文中尝试 15 篇；这一步只下载到项目缓存，不把论文当成已核准数据。可打开预取 PDF 和结果表，然后填写核对人，看摘要及 PDF 决定是否保留。保留后在第 3 步获取正文，会直接使用已预取的 PDF，无需再下载。可点“评分权重”调整六类依据；评分只安排阅读顺序。
3. **正文与提取**：第 3 步点“批量获取待下载正文”，会对所有已保留且尚无正文的论文逐篇尝试；进度显示在窗口上方，点“停止批量”会在当前篇结束后停止。“打开批量结果”可看每篇成功或失败原因，也可只选一篇点“自动获取所选论文正文”。工具识别出版社，已输入 Elsevier key 时优先请求其 PDF 全文接口；Springer Nature key 可查询对应 PDF 链接；随后尝试开放版本和 DOI 论文页面。成功后自动归到对应论文并记录来源。若接口不能提供 PDF，可在有机构权限的浏览器里用插件采集可见正文及下载 PDF、补充材料。把采集包 JSON 导入第 1 步，确认保留后在第 3 步点“自动获取所选论文正文”会优先使用已下载 PDF；点“使用浏览器采集全文”可绑定采集的网页正文及材料。请打开文件核对标题、DOI 和内容后再提取。API key 本身不保证全文权限；本版不接管浏览器登录状态。
4. **对照原文审核**：选左侧数值，右侧显示具体核对问题和高亮原文；“PDF 原始页面”显示对应页，双击图片可放大。检查样品、数值、单位、温度和实验归属后通过或排除。错误或漏提可点“修正 / 补录一条”，复制原文证据，不能填写推测值。补录后仍需人工通过。
5. **导出结果**：点“保存审核结果并导出数据”，再打开结果文件夹，查看已审核观测、性能长表、样品特征表和暂缓导出记录。

## 不知道该核对什么时

- 第 2 步看右侧的三个问题及摘要原文。
- 第 4 步的每条数值都列出催化剂、指标、单位、温度及尚未解决的问题，原文证据高亮显示。
- 绿色高亮表示已关联的温度证据，黄色表示数值证据。文字和 PDF 原始页可相互核对。
- “未提取页”列出规则漏掉的内容块，可补录文字数值或记补提备注。
- “尚未确认文档为原始研究”的记录，可复制原文中能证明作者做了实验的文字，点击“确认原始研究类型”。综述不能直接这样改为原始数据。

## 图片读数和语义候选

第 4 步选中对应原文页，点“打开当前页图片读数”。选择图型，框选绘图区，分别标定横纵轴的两个位置、数值、单位，再按样品取点；单色曲线可尝试颜色追踪。填写图号后导出，按提示关联指标和反应条件。条件需要复制对应原文作为依据。也可用“导入已有图片读数”导入学姐工具导出的“读数与溯源.json”，须保留同目录图片并绑定同一份论文。

图像读数是近似值，导入后仍待科学核对。同一曲线的点保留共同分组，不能当成互不相关的独立实验。本版不自动寻找子图或识别任意图型。

“语义候选”收集比较、提高、抑制和机理描述，保留原句；可单独审核和导出。规则无法确定的样品、基准和条件留空。“提高十倍”不会被改写成转化率或训练标签。

## 保存和继续

程序自动保存到当前项目，原文材料复制到项目中。下次点“继续以前项目”，选择项目文件夹内的 project.json。论文选择、材料绑定、数据审核、补录和历史会保留。重新提取会建立新一轮结果，旧的审核结果仍保存在原轮次目录。

缺少温度的普通性能记录不会进入性能长表；范围、±、不等式、单位不明、未确定样品及综述数据需解决后才能通过。没有通过的数据不会直接导出为训练数据。

本版把既有规则提取接入操作界面，用于批量获取与小批量提取测试；跨论文提取覆盖率仍需评估。AI 调用、机器学习、SISSO、实验和 DFT 未包含在此版中。

浏览器按钮：在 Chrome 的 chrome://extensions 重新加载已安装的 NH3-SCR 插件；若旧插件来自另一文件夹，先移除旧版，再加载本交付包的 browser_extension 文件夹。打开论文并展开正文后，从右上角拼图图标点“读取本页”，再点“下载文件并保存采集包”。保持弹窗打开直到 Chrome 下载结束并保存 JSON；将 JSON 导入工作台第 1 步。插件会尝试当前论文的 PDF、补充材料和图像，未取得的文件只留链接。浏览器下载文件会复制到工作项目，在人工保留前不会用于提取；PDF、图像等可解析材料经确认后可绑定，ZIP 等其他文件留在项目的 captures 文件夹供人工处理。仍须核对实际文件。采集当前页面不等于自动抓取整站或突破付费访问。

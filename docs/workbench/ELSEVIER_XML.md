# Elsevier 官方 TDM XML 接入

2026-10-13 本地更新。继续使用根目录 `OPEN_THIS.cmd`；尚未更新 GitHub Release 或重新打包 EXE。

## 操作

1. 重开工作台，在板块1检索或导入 DOI，核对并保留 Elsevier 论文。
2. 打开“出版社 API 设置 / 验证”，选择“Elsevier：全文 PDF / XML”，填写自己的 API Key。机构 Token 只在官方提供后填写。
3. 点击“获取 XML 正文”验证单篇，或保持勾选“批量获取时优先 XML；未取得时尝试 PDF”，点击“应用密钥（仅本次）”。
4. 回到板块1，点击“自动获取正文 → 进入第二板块”。按出版社自动选择已配置通道：Elsevier XML 成功后可直接进入第二板块，其他出版社仍用原有 PDF 流程。
5. 读取正文，点击证据返回原句，核对样品、条件、指标和单位。核对后的记录按原流程导出给第三板块。自动候选不会直接成为训练样本。

## 正文与定位

- 请求官方 `/content/article/doi/{DOI}?view=FULL`，使用 `X-ELS-APIKey` 和可选 `X-ELS-Insttoken` 请求头，XML格式为 `Accept: text/xml`。
- 保存收到的原始XML字节、文件指纹、请求入口、论文身份核对结果以及正文结构清单。凭据不写入结果。
- 核对主元数据中的 DOI 和题名，要求存在可定位的正文。只有摘要/元数据、服务错误、登录页、错 DOI 或错题名均不会作为全文入队。
- 提取章节下的正文段落，以及表格标题、表头、原单元格、行和列跨度属性。保留Å、ø、±及内联化学式文本；不自动推断缺失单元格、跨行样品或性能与反应条件的关联。
- 参考文献、摘要、图注不混入正文实验候选。图注和公式等不支持结构仍在原XML保留，并不声称已完整理解所有公式或图像。
- XML定位明确显示为“XML段”和章节；证据保存节点路径、段编号、原句字符位置及源XML指纹。内部兼容字段 `page` 对XML表示逻辑段编号；来源对象中的物理 `page` 为null，不伪造PDF页码。
- 第三板块重新读取原XML复验引文及节点路径，不仅信任缓存。原文件改变、节点定位不一致或证据未核对时禁止进入标准化。
- XML不是原版图像。只有XML时不允许曲线标定；另行取得PDF后再读图。若已有有效PDF，交接仍优先使用PDF档案，并保留XML作为单独来源附件，不混写两种来源的审核。

## 下载规则

单篇“获取XML正文”只请求XML。批量优先XML时，非认证/限流失败可再尝试PDF；401、429不会换格式重复请求。两种请求结果分别保留。公开PDF回退沿用已有流程；没有正文时仍保留原权限或网络错误。

原PDF不会被XML覆盖。已有XML每次复用会校验内容与接收时的指纹；缓存结构JSON不是科学原始来源，第二、三板块从XML重新解析。

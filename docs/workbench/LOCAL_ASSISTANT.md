# 本机模型：先给建议，再由用户核对

本地更新：2026-10-13。模型入口使用官方 Ollama，本次配置 Qwen3 4B。模型和运行程序位于忽略目录 `local_models/`，不会打包上传 GitHub。模型判断时只向本机 `127.0.0.1:11434` 发送原句及其附近上下文，不需要出版社 API Key。

## 怎么操作

1. 重开第二板块，进入“语义”页。
2. 首次点“安装 / 启动本机模型”；本机下载需要数 GB 和足够空间。安装状态保存在 `runtime_data/local_assistant/setup.log`。
3. 点“全篇生成分类建议”，程序为尚无建议、尚无人工作决定的语义候选生成用途、中文说明、依据与需要核对的问题。已有建议复用，已人工决定的条目跳过。
4. 选一条，点“查看建议并确认”。默认显示原文、中文说明、建议用途与依据，分类菜单收起。没有建议时，已装好的模型会自动判断当前句子。
5. 建议合适时填写一次姓名或代号，点击“确认当前建议并保存”；想改分类时才展开“修改分类”。未确定的条目可“暂存，稍后核对”。

模型提供的中文说明是辅助转述，不代替完整论文翻译。未安装模型时仍可显示明确标记的规则初步建议，不会把规则输出冒充大模型结果。

## 模型做什么

- 推荐用途：机理、比较、条件、耐久性、测量信息、背景或待确认等。
- 用中文简要解释这句原文，并给出判断依据。
- 逐字引用原句中的片段；引用不在当前原文中时拒收。

模型建议独立保存为 `assistant_suggestion`，带模型名称、版本、原句和来源文件标识。它不会覆盖原数值、原样品、原实验条件或已有人工采纳决定；自动生成建议不会使证据成为“已审核”，也不会生成机器学习标签。确认用途后，建立性能记录仍需要实际数值、样品与对应条件。

例如“NH3 coordination increases the energy barrier for Cu+ diffusion...”通常建议保留为机理解释，而不是转化率观测。<20%这样的边界不能改成恰好20%的样本。

## 代理兼容

官方 Ollama 拉模型若因代理 Fake-IP（198.18.*）拒绝官方存储重定向，安装脚本可从同一官方 Registry 接收模型分层，核对每层官方摘要和大小后写入本机缓存。不修改代理全局规则，也不关闭 Ollama 的重定向检查。若本机运行的是其他 Ollama 实例，且使用不同模型目录，脚本会检查模型能否被接口识别，不会把未就绪状态报为成功。

官方资料：[Ollama Windows](https://docs.ollama.com/windows)、[结构化输出](https://docs.ollama.com/capabilities/structured-outputs)、[Qwen3 4B 模型](https://ollama.com/library/qwen3:4b)。

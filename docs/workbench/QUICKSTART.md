# 最新三板块工作台使用教程

更新：2026-10-09。适用 Windows 10/11；建议 64 位 Python 3.11 或 3.12。所有入口使用同一份最新代码。

## 1. 第一次怎么打开

1. 从仓库 [Releases](https://github.com/Chirune/nh3_scr_tool/releases/latest) 下载 `CatalystWorkbench-All-Latest.zip`，完整解压。也可以下载仓库源码 ZIP 后解压。
2. 如果电脑没有 Python，从 [Python 官方网站](https://www.python.org/downloads/windows/) 安装 3.11 或 3.12，保留安装器中的 Tcl/Tk、pip 和 Python Launcher。
3. 双击根目录 `start_workbench.cmd`。第一次会联网安装依赖到项目自己的 `.venv` 文件夹，然后打开整合窗口；以后直接启动。命令窗口不要提前关掉。
4. 不要在 ZIP 里面直接双击程序。不要只复制某一个 `.py` 文件。整合窗口出现后，默认从 **板块1** 开始。
5. 没有论文也可以点“无论文也能试：合成演示”。它在本机生成一篇明确标为合成的 PDF；所有值都是教学数据，不能进入正式研究集。

开发者可在解压目录执行：

```powershell
py scripts/setup_workbench.py --team-tools
.venv\Scripts\python.exe start_workbench.py
```

## 2. 三个板块各做什么

| 板块 | 读入什么 | 操作重点 | 交给下一步什么 |
| --- | --- | --- | --- |
| 1：文献获取与筛选 | 检索词、DOI、PDF文件夹或组员采集项目 | 选方向，查来源，人工保留/排除；取得有效 PDF | `run.json` 与关联全文 |
| 2：单篇论文证据 | 板块1记录或已有论文档案 | 数值/表格、语义、图像三路核对；绑定同一条样品与实验条件 | `paper.json` 档案及导出的 `待编码包.json` |
| 3：编码与模型准备 | 一篇或多篇 `待编码包.json` | 统一目标、单位、条件；检查 X/y；质量分与性能分分别看 | 标准化表、X/y、来源及缺失清单、模型输入准备 |

研究目标是根据催化剂配方与实验条件预测相应性能。NH₃-SCR 的 NO 转化率、铜锌制甲醇任务和氨吸附能是不同任务；不能把名称不同、条件不同的数据直接混成一个标签。

## 3. 板块1：已有 PDF 或自动获取都可以

1. 点击“打开1号板块”，选择 NH₃-SCR 或铜锌方向。
2. 有 PDF 时点“导入本地 PDF 文件夹”；有 DOI 时点“导入 DOI”；需要新文献时输入关键词后检索。
3. 在列表选一篇，查看原文身份与初筛理由，再人工判定“保留”“待复核”或“排除”。
4. 点击顶部 **“自动获取 PDF → 进入第二板块”**。已关联的 PDF 直接复用；其他论文尝试当前支持的开放路径或已配置出版社接口。
5. 只有题录不等于有全文。失败原因保留在列表，不会把 XML、登录页或错误页伪装成 PDF。403/404 不要反复空点；核对选中的论文、接口权限，或使用学校网页与 Zotero 接收。

学校登录和 API 访问是不同入口。当前整合保留已有接口，没有新增出版社权限。账号密码不要写进代码；本次会话密钥不进入源码仓库。

## 4. 从组员现有工具接过来

整合入口中的“组员采集与浏览器工具”仍可打开仓库原有工具，原浏览器扩展安装方法见 [浏览器采集说明](../BROWSER_CAPTURE.md)。

在原工具完成论文人工保留并关联正文后，回到整合入口点 **“导入组员采集项目”**，选择那个项目的 `project.json`。

- 导入论文题名、DOI、人工筛选决定、备注，以及能确定的唯一正文 PDF。PDF复制到新运行目录，原项目不被修改。
- 尚无人工决定的论文继续待复核；被排除的论文仍排除。
- 多个正文 PDF、缺失文件、补充材料或只有 HTML 时，不擅自选择正文。
- 原工具数值审核属于原来的证据结构，**不会自动变为新版已审核训练标签**。原记录保留在原项目，需在新版中核对来源后接续。

## 5. 板块2：按照一篇论文逐步核对

### ① 数值 / 文字 / 表格

点击“读取全文并提取数值”，先看数值清单。区分目标性能、实验条件与材料属性。比如“反应温度300℃”是条件，“NO转化率90%”才可能是这项预测任务的目标。

“对应样品/实验待确认”表示数值已经找到，但尚未确认属于哪个样品或哪次测试。点“回到原文核对”核实后，再“建立性能记录”或“补充条件/特征”。小于号、区间、近似值、预测值都保留原来含义。

### ② 语义关系与中文阅读

检查比较主体、对照样品、指标、倍数/比值、适用条件和陈述性质。定性趋势、否定、展望、稳定性、失活、恢复等可以保留为待核对的关系，不必强行转换为性能数字。

“提高了10倍”和“变为10倍”不能直接混用；只有相对描述而没有可靠基准，不能造出绝对性能。确认句子含义之后，再决定保留为比较、定性、条件、机理解释或背景。

英文下方有中文参考译文、术语解释和阅读提示。首次使用从整合入口点 **“安装中文翻译”**：需要联网取得公开模型，约71MB归档另加运行依赖；安装进度在数据目录的日志中。之后翻译在本机执行，不发送论文原文。无模型时术语解释仍可用。

也可以执行：

```powershell
.venv\Scripts\python.exe scripts/setup_translation.py
```

译文是阅读辅助，不替代原句、人工审核或训练标签。

### ③ 图片核验

1. 在本篇的图片分支扫描或打开候选图，优先查看带图号/图注的图片。
2. 核对裁剪范围；包含坐标轴、刻度和图例。组合图应按完整坐标区拆成子图，支持拖框修改。
3. 自动读数后先看坐标、横纵轴单位、图例系列，以及叠加在原图上的点。
4. 修正并审核后导出读数与来源，再返回本篇点击 **“刷新图片读数”**。

不是每种图片都有可用的性能标签。结构示意图、装置图不能硬转性能；谱线采样点不能当成很多次独立催化实验；多系列、误差线、重叠点及低清图仍可能需要人工修正。Windows OCR识别依赖系统支持，文字识别失败时应核对系统语言组件或手动修正。

### ④ 综合审核 / 编码交接

把文字、语义和图像证据关联到同一条 **样品—实验条件—性能** 记录。三路说同一次实验，不应变成三个样本。存在缺失、冲突或来源过期时先处理待办。

点击“进入第三板块”会先导出当前待编码包并打开编码窗口，不需要重新手工找文件。

## 6. 板块3：怎么看结果

1. 选择一致的预测任务，再添加其他论文的待编码包。
2. 看“标准化记录”和“未纳入与缺失”：单位、指标定义、条件不满足要求的记录会说明原因。
3. 看“编码检查预览 X/y”：X为预测前可获得的输入，y为要预测的结果。未报告不等于0；不能拿预测后才知道的信息直接当输入。
4. 看“质量分/性能分”：前者看证据和数据可用程度，后者必须在指标与条件可比时讨论。两种分数不混为一分，也不替代实验标签。
5. 看“机器学习准备”：按论文分组，先分训练与验证；填补、缩放和类别处理只依据相应训练折。不同模型有对应输入准备方案。
6. 导出之后从输出文件夹的“先看这里”页面进入，核对标准化表、X/y、缺失表与来源。

如果显示0条，先看未纳入原因，再回到板块2补齐证据和必要条件。这个页面当前准备模型输入，**没有训练或比较出最准确的新模型**；DFT验证属于后续研究任务。

## 7. 数据在哪里，怎样继续

程序默认只向根目录 `runtime_data/` 写入运行结果。分板块与整合版入口共用它。不要把这个目录提交到公开仓库。

- `筛选结果/`：每次筛选的 `run.json`、CSV、获取记录。
- `论文综合结果/`：单篇 `paper.json`、原文来源、审核及导出。
- `图片处理结果/`：候选裁图、读数会话、CSV、原图叠加核对。
- `编码结果/`：标准化、编码、评分及模型输入准备。
- `日志/`：启动错误与本地翻译安装进度。

点“继续已保存的数据”选择相应文件。不要把CSV当成唯一档案，也不要同时在两个窗口修改同一篇论文。更换电脑时同时带走原 PDF 与完整项目文件夹，移动之后核对源文件关联；程序不会自动猜测失效路径。

## 8. 分板块版和整合版有什么区别

三个 `modules/stage*/` 文件夹各有入口和说明。四个发布ZIP使用同一版本底层代码，区别是默认入口和教程定位。分板块包仍带共享组件，以保证交接和回到原文能工作；不需要同时安装四份。

普通组员优先下载整合版。分工开发时根据 [代码地图](ARCHITECTURE.md) 找到负责的文件。

## 9. 常见问题

| 现象 | 处理 |
| --- | --- |
| 双击一闪而过 | 在解压目录运行 `.venv\Scripts\python.exe start_workbench.py --check`；查看 `runtime_data/日志`。缺Python时先装3.11/3.12。 |
| 界面只有空列表 | 初次打开尚未载入记录；从板块1开始，或选择已有 `run.json`/`paper.json`。 |
| 点击导出没有数值 | 导出不会替你创造测量值；先核对读数是否生成、是否审核、是否已回传本篇。 |
| 中文译文未就绪 | 安装中文翻译组件并查看安装日志；完成后重开板块2。不要填出版社API Key来解决翻译问题。 |
| 有数值但不能编码 | 查看样品、条件、单位、来源与审核状态；区间/趋势不自动等同于精确标签。 |
| 想知道哪个模型最准 | 先积累经核验的真实数据，再在同一任务和分组划分上比较；当前没有这个结论。 |

公开版本含源码、教程和合成测试。个人PPT、专利资料、付费论文、账号密码、模型权重和科研档案均不在源码包中。

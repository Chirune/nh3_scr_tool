# 第一板块：新增摘要来源与补全

本地更新日期：2026-10-12。修改原有第一板块，沿用 `OPEN_THIS.cmd` 入口。尚未发布新版 Release 或重新打包 EXE。

## 怎么用

1. 重新打开工具，进入第一板块。
2. 来源中可选择 Crossref、OpenAlex、Europe PMC。输入检索词或导入 DOI。
3. 默认勾选“自动补齐缺失摘要”：按 DOI 对缺摘要记录补查 OpenAlex，每批最多50个 DOI。按 DOI 去重，同一论文不因为多一个来源变成两个样本。
4. 如 OpenAlex 提示匿名额度不足，点击“检索平台 Key”→对应“申请 / 说明”，取得自己的 OpenAlex Key 后填入。与 Elsevier Key 不同；仅本次会话使用，不保存到配置、结果或缓存。
5. 选一篇论文，直接查看摘要、摘要状态、来源和出处，然后人工保留、待复核或排除。
6. 已有任务也可以打开，再点击“补齐已有结果的摘要”。已有记录ID、人工决定、备注与PDF关联保留。

## 做了什么

- 新增 OpenAlex 关键词检索及 DOI 查询，重建 `abstract_inverted_index` 中的原摘要词序。
- 索引缺口、位置冲突或非法位置会标为无有效摘要，不补猜缺失词。
- 摘要来源、OpenAlex记录ID、原始来源记录及补全请求状态写入 `run.json`；CSV、结果HTML和界面同时显示来源。
- 同 DOI 合并时保留一份完整摘要和它对应的来源，其他版本保留在原始来源记录里，不把多个片段拼成新摘要。
- 仍缺有效摘要的API题录自动转待复核；原始关键词覆盖比例继续保留，不当作准确率或新的论文价值评分。
- OpenAlex报告的开放获取位置交给现有PDF获取流程；链接仍需身份和文件检查，不声称已获得全文。
- 补全已保存的任务时更新元数据与自动初筛，已有人工判断优先，已关联PDF不被替换。改变摘要来源会有元数据更新事件记录。
- 缓存有效期24小时。新检索不重复补查本批已来自OpenAlex的缺摘要记录；对已保存结果可以重新补查，缓存过期后才重新请求。
- OpenAlex返回授权/额度错误时停止本批剩余补查，保留其他来源的结果。未填写Key时不继续重复请求已耗尽的共享额度。
- 本地PDF模式仍只在本地读取；前两页文字明确标为片段，不冒充准确定位后的摘要，不触发摘要联网补全。

## 验证与限制

新增21项离线检查覆盖词序还原、缺口与冲突、DOI身份、摘要来源、合并去重、限流停止、缓存、取消和旧任务人工决定/PDF关联保留。

2026-10-12匿名联网测试：Crossref取得3篇，其中1篇含摘要、2篇缺摘要；OpenAlex匿名检索与DOI补全均返回429，报告当前公网IP共享额度耗尽。程序保留结果并把缺摘要论文转待复核。

2026-10-13填写个人OpenAlex Key后，关键词检索与DOI查询均成功：Crossref和OpenAlex各检索5条，补查4个DOI，合并得到10篇论文，其中2篇有摘要（各来自Crossref和OpenAlex），8篇仍缺摘要。4个DOI补查均取得题录，但没有提供摘要，因此没有新增摘要。旧任务的2个缺摘要DOI也查询成功，记录ID保留；旧任务仍保留前一天的429历史，新请求没有新增错误。验证结果位于本地忽略目录 `runtime_data/openalex_live_20261013/validation.json`，个人Key没有写入文件。这里验证的是检索与摘要查询，不代表已取得全文或形成可训练数据集。

此更新只增强第一板块的元数据与摘要。不新增未经验证的100分权重，不从摘要补造实验条件或性能，不改动已提取的46条真实曲线草稿。Elsevier校园网络/API权限的对照测试另行处理。

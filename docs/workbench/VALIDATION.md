## 如何复跑

```powershell
py scripts/setup_workbench.py --team-tools
.venv\Scripts\python.exe scripts/test_shared_workbench.py --report runtime_data/validation.json
```

共享版把三个板块和原采集工具分组放到独立测试进程，避免同名模块互相干扰。`tested_dependencies.txt`为此次实际安装版本，常规安装入口保留兼容范围。仅在依赖或代码变化时重新验证。

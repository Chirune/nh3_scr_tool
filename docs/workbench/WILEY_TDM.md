# Wiley：本地接入与实测结果

更新：2026-10-13。本次修改在本地工作台生效，尚未重新发布 Release 或 EXE。凭据仅本次会话使用。

## 使用

1. 重开工作台，进入板块1，导入 Wiley 论文 DOI，查看摘要并决定保留。
2. 打开“出版社 API”，选择“Wiley：TDM 全文 PDF”，填写自己的 TDM Token，点击“应用密钥（仅本次）”。
3. 先验证当前选中论文；取得有效 PDF 后进入第二板块核对原文数据。

Wiley 默认直连，不使用 Windows 为其他服务配置的 HTTP 代理。系统级 VPN/TUN 和域名分流仍可能影响出口；直连不等于校园网络。订阅全文还需机构权限。批量请求沿用至少10.1秒间隔，遇到限流暂停。

## 本次验证

- 用户下载的 Wiley 官方客户端 `wiley-tdm 1.2.0` 已安装到工作台虚拟环境，官方下载源码未修改。后续本地更新已将它作为默认下载后端，并加入依赖安装清单。工作台保留限流、取消、文件大小限制、凭据跳转控制及PDF身份核验；官方状态码不直接当成科学数据有效性判断。
- `10.1002/cctc.202301214`：官方客户端直连取得PDF；修复后的工作台通道也取得PDF，8271338字节、20页，DOI与题名核验通过。该文是开放获取综述，仅作为下载和文档读取测试，不作为新增独立实验样本。
- 同一开放论文走当前系统代理时发生超时。
- 实验论文 `10.1002/cctc.202500194`：系统代理与直连都返回403，尚未取得全文。开放论文成功不代表本篇订阅/API权限已经满足；后续需校园网络对照，或向Wiley确认Token登记与文章访问权限。
- 未形成新的机器学习数据集；全文仍需进入板块2提取和核验。

## 本地修复

- Wiley下载默认关闭该客户端的系统HTTP代理使用，不修改电脑代理设置，也不影响其他出版社。
- 本机代理DNS将 `api.wiley.com` 和 `alm.wiley.com` 映射到198.18.0.0/15假IP段。仅这两个固定官方域名允许该假IP映射；其他域名仍检查公开地址，私网、回环地址与混合私网解析仍拒绝。
- 跳转到 `alm.wiley.com` 后不携带Token；导出只保留原始API入口，临时签名下载网址不入报告。
- 单篇403保留文章权限/网络诊断，不禁用整枚Token；401/400仍暂停凭据，429仍按限流暂停。

本地实测记录和PDF位于 `runtime_data/wiley_diagnostic_20261013/`，不进入GitHub分享包。
